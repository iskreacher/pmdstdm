# PMDSPT

PMDSPT — расширение для VS Code, объединяющее таймер Pomodoro и режим Panic Mode.

## Возможности

- Постоянное отображение в status bar:
  - `🍅` / `💀` — переключение между Pomodoro и Panic Mode;
  - таймер — запуск, пауза и продолжение отсчёта;
  - `⚙` — настройки таймера и звуков.
- Рабочие интервалы и перерывы Pomodoro.
- Panic Mode с произвольной длительностью.
- Сохранение состояния таймера в хранилище расширения VS Code.
- При запуске расширения Pomodoro сбрасывается на начальную рабочую фазу.
- Состояние Panic Mode восстанавливается после перезапуска VS Code.
- Постоянное уведомление о перерыве с возможностью закрытия вручную.
- Четыре звуковых события:
  - начало отдыха;
  - начало работы;
  - запуск Panic Mode;
  - завершение Panic Mode.
- Встроенные WAV-звуки и возможность выбрать собственные WAV-файлы.

## Управление через status bar

В status bar отображаются текущий режим, оставшееся время и кнопка настроек:

```text
🍅 25:00 ⚙
```

При нажатии на таймер выводится одно из трёх состояний: `timer started`, `timer stopped` или `timer resumed`.

## Panic Mode

Откройте меню `⚙` и выберите `Set Panic Mode time`. Время можно указать в одном из форматов:

- минуты: `10`;
- минуты и секунды: `05:30`;
- часы, минуты и секунды: `01:05:00`.

После завершения Panic Mode таймер сбрасывается на стандартную длительность, а следующий запуск считается новым запуском.

## Настройки звуков

В меню `⚙` выберите `Sound settings`. Доступны следующие действия:

- включить или отключить все звуки;
- выбрать звук для каждого события;
- отключить звук отдельного события;
- вернуть встроенные звуки по умолчанию;
- выбрать собственный WAV-файл.

Выбранные пользовательские звуки копируются в глобальное хранилище расширения, поэтому исходный файл можно переместить.

## Разработка

Необходимое окружение:

- Node.js;
- npm;
- VS Code или Code OSS.

Установка зависимостей:

```bash
npm install
```

Проверка и сборка:

```bash
npm run check-types
npm run lint
npm run compile
```

Для запуска Extension Development Host откройте проект в VS Code и нажмите `F5`. Выберите конфигурацию `Run PMDSPT Extension`.

Стандартные интервалы расширения:

```text
Рабочий интервал Pomodoro: 25 минут
Перерыв Pomodoro: 5 минут
Стандартная длительность Panic Mode: 5 минут
```
